DSA01 Assignment 1 — Separate C++ Task Codes

There is one .cpp file per task in its own folder. Tasks 1–12 align with the Metro Smart-Card assignment.

Compile a file from its folder:
    g++ -std=c++17 -Wall -Wextra Task01_Objects_OOP_Analysis.cpp -o task

Windows PowerShell:
    .\task.exe

Linux/macOS:
    ./task

Task 8 waits for keyboard input. Enter a valid hour from 0 to 23. Try entering letters first to observe input validation.

Important:
- Tasks 1 and 2 are mostly analysis tasks in the brief; the included programs demonstrate the related concepts.
- For Task 4 and Task 5, write your predicted output before running the programs, as required by the assignment.
- Task 9 includes five automated fare tests. Add the extra boundary and invalid-input cases listed in the brief.
- Task 12 assumes the weekend discount takes precedence over the peak surcharge; state this assumption in your report.
- Run every program yourself and save your actual output screenshots. Review each program so you can explain it during viva.
