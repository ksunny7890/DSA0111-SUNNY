TASK B3 – VIRTUAL FUNCTIONS VS SWITCH VS EXCEPTIONS (8 MARKS)
=============================================================

B3.1 CORRECTNESS ON SMALL DATA
------------------------------
Use the same 10 bills in both implementations. Example test data:
OP: 500 + 1200 = 1700
IP: 3*2500 + 40000 = 47500
Repeat these two bill patterns five times (five OP and five IP).

Total = 5*1700 + 5*47500 = 5*49200 = 246000.
Both virtual and switch implementations must print 246000. If they differ, the
type selection or one of the formulas is incorrect.

Switch representation:
struct PlainBill { int type; int days; double a, b; };
// type 0: a+b (OP); type 1: days*a+b (IP)
double total(const PlainBill& x) {
    switch (x.type) {
        case 0: return x.a + x.b;
        case 1: return x.days * x.a + x.b;
        default: throw std::invalid_argument("unknown bill type");
    }
}

B3.2 / ALTERNATIVE std::variant BENCHMARK
------------------------------------------
A benchmark was compiled with g++ 14.2.0 using:
g++ -std=c++17 -O2 -DNDEBUG b3.cpp -o b3
It used 50% outpatient and 50% inpatient bills, prebuilt containers, and timed
only the total-calculation loops. Results from one run:

Number of bills    Virtual (ms)    Switch (ms)    std::variant (ms)
1,000              0.003           0.001          0.001
1,000,000          4.620           2.446          3.267
10,000,000         65.673          40.715         40.830

All methods computed the same total. These are illustrative measurements from
one machine/run, not universal constants. Repeat several times, report the
median, and avoid comparing runs made under different system loads.

The 10-bill correctness total is 246000. For the 1,000,000 and 10,000,000
benchmarks, the same 50/50 mix gives per-bill average (1700+47500)/2=24600,
so totals are 24,600,000,000 and 246,000,000,000 respectively.

BENCHMARK METHOD
----------------
1. Build all input containers before starting the timer.
2. Use -O2 for every version.
3. Time only the processing loop using std::chrono::steady_clock.
4. Store/print the computed sum so the compiler cannot discard the work.
5. Run at least five times and compare medians.
6. Record CPU, compiler, compiler flags and operating system with the results.
The measurements above are a sample run; your computer may produce different
values. At 10 million elements, memory allocation and cache behaviour matter.

B3.3 COST OF EXCEPTIONS
-----------------------
One million validations, using a return/skip path versus throwing and catching
std::invalid_argument for invalid values, produced this sample:

Invalid bills    Return-code (ms)    Exceptions (ms)
0%               1.536               0.984
1%               0.916               16.795
50%              1.183               626.792

The 0% result is affected by normal timing noise and optimization; it does not
mean exceptions are intrinsically faster. At 1% and especially 50%, exception
handling is much more expensive. Repeat runs and use medians for a report.

B3.4 ENGINEERING TRADE-OFF
--------------------------
Virtual functions:
- Best when many unrelated derived types must be stored and processed uniformly.
- Easy to add a new derived bill type without changing the processing loop.
- Has an indirect call and commonly a pointer-based container/allocation cost.

Switch:
- Often fast and compact for a small, closed set of bill types.
- Adding a type requires changing the switch and every relevant dispatch site.
- Invalid type values must be handled explicitly.

std::variant + std::visit:
- Stores one of a known set of types inline, with a discriminator tag.
- No separate heap allocation is required for each alternative when stored in
  a vector<variant<...>>.
- visit dispatch is type-safe and often optimized well; adding an alternative
  still requires updating the variant type and visitors.
- Approximate element size is sizeof(largest alternative) plus tag and padding;
  exact size is implementation-dependent.

Exceptions:
- Suitable for exceptional failures such as corrupted input, I/O failure or
  unexpected infrastructure errors.
- Avoid using thrown exceptions for frequent, expected invalid-claim decisions;
  use optional, expected/result values or return codes.

ALTERNATIVE TEMPLATE DESIGN
---------------------------
Keep vector<OutPatient> and vector<InPatient> separately and write a templated
sum function. The compiler generates concrete loops; calls can be inlined.
Time remains O(N). It is efficient but does not itself provide one heterogeneous
container. For one mixed collection, variant or virtual base pointers are more
appropriate.

CONCLUSION
----------
In this sample, switch and variant loops were faster than virtual dispatch,
but all were O(N), and the measured gap depends on layout, allocation, compiler
and CPU. Choose the design primarily for maintainability and type requirements;
benchmark the actual production workload before optimizing.


APPENDIX: REPRODUCIBLE BENCHMARK PROGRAM (b3.cpp)
------------------------------------------------
This compact program measures the three calculation loops and exception costs.
It uses C++17 because std::variant requires C++17.

#include <iostream>
#include <vector>
#include <variant>
#include <memory>
#include <chrono>
#include <stdexcept>
#include <type_traits>
using namespace std;

struct Base {
    virtual ~Base() = default;
    virtual double total() const = 0;
};
struct OP : Base {
    double c, t;
    OP(double x, double y) : c(x), t(y) {}
    double total() const override { return c + t; }
};
struct IP : Base {
    int days; double rate, surgery;
    IP(int d, double r, double s) : days(d), rate(r), surgery(s) {}
    double total() const override { return days * rate + surgery; }
};
struct Plain { int type, days; double a, b; };
struct VOP { double c, t; };
struct VIP { int days; double rate, surgery; };
using AnyBill = variant<VOP, VIP>;

volatile double resultSink = 0;
template<class F>
double timeMs(F f) {
    auto start = chrono::steady_clock::now();
    double result = f();
    auto stop = chrono::steady_clock::now();
    resultSink = result;
    return chrono::duration<double, milli>(stop - start).count();
}

int main() {
    for (int n : {1000, 1000000, 10000000}) {
        vector<unique_ptr<Base>> virtualBills;
        vector<Plain> switchBills;
        vector<AnyBill> variantBills;
        virtualBills.reserve(n);
        switchBills.reserve(n);
        variantBills.reserve(n);

        for (int i = 0; i < n; ++i) {
            if (i % 2 == 0) {
                virtualBills.push_back(make_unique<OP>(500, 1200));
                switchBills.push_back({0, 0, 500, 1200});
                variantBills.push_back(VOP{500, 1200});
            } else {
                virtualBills.push_back(make_unique<IP>(3, 2500, 40000));
                switchBills.push_back({1, 3, 2500, 40000});
                variantBills.push_back(VIP{3, 2500, 40000});
            }
        }

        double virtualMs = timeMs([&] {
            double sum = 0;
            for (const auto& b : virtualBills) sum += b->total();
            return sum;
        });
        double switchMs = timeMs([&] {
            double sum = 0;
            for (const auto& b : switchBills) {
                switch (b.type) {
                    case 0: sum += b.a + b.b; break;
                    case 1: sum += b.days * b.a + b.b; break;
                    default: throw runtime_error("bad type");
                }
            }
            return sum;
        });
        double variantMs = timeMs([&] {
            double sum = 0;
            for (const auto& b : variantBills) {
                sum += visit([](const auto& x) -> double {
                    using T = decay_t<decltype(x)>;
                    if constexpr (is_same_v<T, VOP>) return x.c + x.t;
                    else return x.days * x.rate + x.surgery;
                }, b);
            }
            return sum;
        });
        cout << n << " bills: virtual=" << virtualMs
             << " ms, switch=" << switchMs
             << " ms, variant=" << variantMs
             << " ms; total=" << resultSink << '\n';
    }

    for (int invalidPercent : {0, 1, 50}) {
        vector<double> values(1000000, 100.0);
        for (int i = 0; i < 1000000 * invalidPercent / 100; ++i)
            values[i] = -1.0;

        double returnMs = timeMs([&] {
            long accepted = 0;
            for (double x : values) if (x >= 0) ++accepted;
            return static_cast<double>(accepted);
        });
        double exceptionMs = timeMs([&] {
            long accepted = 0;
            for (double x : values) {
                try {
                    if (x < 0) throw invalid_argument("negative");
                    ++accepted;
                } catch (const invalid_argument&) {
                    // Rejected claim; continue with the next claim.
                }
            }
            return static_cast<double>(accepted);
        });
        cout << invalidPercent << "% invalid: return=" << returnMs
             << " ms, exceptions=" << exceptionMs << " ms\n";
    }
}

Compile and execute:
g++ -std=c++17 -O2 -DNDEBUG -Wall -Wextra b3.cpp -o b3
./b3
